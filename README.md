## 先搞清楚 CN2 这条谱系，钱才花得明白

"CN2"经常被当成一个笼统的好词用，实际上它下面分了好几档，差价就出在这里。

**普通 163 线路（AS4134）** 是中国电信的普通骨干网，国际出口和所有人共享。它的典型表现是白天还行、晚高峰崩：延迟冲到 300ms 以上，丢包率超过 10%，网页图片加载到一半停住。很多人第一次买美国 VPS 图便宜，买的就是这个，然后在晚上八点发现后台打不开。

**CN2 GT** 是 CN2 的普通级产品，去程经常走 CN2 节点，但回程不一定走优化路由。它比 163 稳一些，可高峰期照样会抖，属于"看运气"的档位。

**CN2 GIA**（China Telecom Next Carrier Network Global Internet Access，号段 AS4809）是电信 CN2 的最高等级，特点是去程和回程都走高端优化线路，回程基本全部落在 59.43 高速节点上——少数省份没有 CN2 GIA 节点，会借道 202.97。因为定价高、用户少，平时带宽有富余，晚高峰也不会被挤爆。

## 判断一台美国 CN2 VPS 值不值，看三件事

**第一件：回程到底走不走 CN2 GIA。**

商家页面写"CN2"不代表回程优化，很多只是去程走了一下。判断方法很直接，SSH 上去跑一条命令：

bash
wget -qO- git.io/besttrace | bash


它会测北京、上海、深圳三地的电信、联通、移动共 8 个节点，外加成都教育网。看回程路由里有没有连续出现 59.43 开头的节点，有就是走了 CN2 GIA。去程可以到 ping.pe 上看是否绕路，但一般来说，只关注回程就够了——回程才是国内用户下载网页、拉取数据的那个方向。

**第二件：带宽和流量是两个不同的约束。**

这是最容易被忽略的一点。所谓"不限流量"，本质是把限制挪到了带宽上。1Mbps 长期跑满，一个月理论上也就 300GB 出头；5Mbps 约 1.6TB；10Mbps 约 3.2TB。反过来，"限流量 + 高带宽"的产品，带宽只是峰值，真正卡住你的是那个流量数字。

所以看到"不限流量"四个字先别激动，先算一下那个带宽满速一个月能跑多少。如果算出来是 300GB，那它对你的实际意义和"300GB 流量"没差多少，只是你不用盯着计数器而已。

**第三件：除了线路，这台机器还给你什么。**

原生 IP 能不能解锁你需要的服务、有没有 DDoS 防御、能不能加 IP、超量之后是停机还是降速、被墙了能不能换 IP。这些条款在出问题的那一天，价值可能超过线路本身。

## 常见问题

**CN2 GIA 和 CN2 GT 到底差在哪？**

差在回程。GIA 去程回程都走高端优化线路，回程基本落在 59.43 节点；GT 是 CN2 的普通级，去程常优化但回程不保证。实际体感上，GIA 在晚高峰能稳住，GT 会抖。价格差通常在两三成到一倍之间，取决于商家。

**洛杉矶 CN2 GIA 到国内延迟多少？**

多方测速的口径是往返 150–180ms，电信方向表现最好，平均可低至 162ms 左右，三网基本接近 0 丢包。对比普通 163 线路晚高峰 300ms 以上、丢包超过 10%，差距主要不在平均值，而在峰值时段的稳定性。

**怎么验证商家说的是不是真的？**

跑回程测试：`wget -qO- git.io/besttrace | bash`，看路由里有没有连续的 59.43 节点。买之前可以用试用款先测——丽萨主机的 CERA 试用款 2 元一天，比买完再退款省事。

**流量用超了会直接断站吗？**
